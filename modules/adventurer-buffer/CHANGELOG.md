# Changes

## 0.4.3

Adds a small server-owner help footer to NPC dialogue, pointing to
`config/module.ini` for buff strength, duration and level range, and explaining
that a game-server restart applies changes. Buff behavior, button layout,
placements and defaults are unchanged from 0.4.2.

## 0.4.2

Three owner-selected strengths: Basic, Mid and editable Custom. Custom starts
with the high-end recipe; release defaults remain Basic, one hour, levels 1-32.
