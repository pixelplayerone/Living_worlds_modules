# Recipe Book

A Community Board tab (Alt+B) that turns the server's recipe data into a progression guide: what you can craft,
what it needs, what you already hold, and where each missing piece comes from. Browse-only: it changes nothing in
the world and adds no items, skills, or NPCs.

## What goes in the book
Only recipes a player can actually obtain: a recipe is listed when its scroll is dropped or spoiled by at least
one monster, or rewarded by a quest. On the stock datapack that is about 549 of 871 recipes (the server log prints
the exact numbers when the book is first opened).

## Pages
- **Front page** - search box and a category by grade grid of recipe counts.
- **List** - recipes of one category and grade, 10 per page, with craft level, success rate, and where the scroll
  comes from (Drop, Quest, or both). A green star marks recipes the player already knows.
- **Recipe** - product, craft level, dwarven/common, success rate and MP, where to get the scroll, and every
  ingredient with needed against held (inventory + warehouse, red when short), plus Add to goals.
- **Ingredient / item** - which monsters drop or spoil it (click a monster to mark it on the minimap), which
  quests reward it, and which recipes use it.
- **Search** - one box matches recipe, product, scroll, and ingredient names.
- **My Goals** - up to 15 pinned recipes, a "Recipes to find" list, and one combined shopping list of every
  ingredient (need, have, missing, most-missing first). Goals are stored per character.

## Install
1. Copy the `recipe-book` folder into `game/modules/`.
2. Set `Enabled = True` in `config/module.ini`.
3. Restart.

`.recipebook` in chat also opens the book, and `.clearmark` removes the map marker a monster trace left (the front
page has a Clear map marker link too).

## Configuration (`config/module.ini`)
- `Enabled` - master switch. Off registers nothing and the server is stock.
- `TabLabel` - text on the navigation button (default `Recipe Book`).

## How it knows things
Recipes, items, and monster drops are read from the loaded datapack the first time anyone opens the book, so XML
edits show up after a restart. Shown chances are base drop chance times the server's rates (capped at 100%);
premium and buff bonuses are not included. Quest rewards live in the quest scripts: `scripts/QuestSources.java` is
generated by `tools/gen_quest_sources.py` from the quests' reward calls. Regenerate it if you add or change
quests: `python3 tools/gen_quest_sources.py <server>/data > scripts/QuestSources.java`.

## Known limits
- Merchant sources are not indexed.
- Any monster template with the drop counts as a source, even one that never spawns.
- Quest sources name the quest, not the NPC to talk to.

## Remove
Disable it, stop the server, delete the folder. No ids or database tables.
