# L2 Living Worlds - Modules

Reviewed and approved modules for the **L2 Living Worlds** server (a fork of L2J Mobius CT_0 Interlude).

Every module here has been reviewed before publishing. Each one is a self-contained folder you drop into your
server's `game/modules/` directory. Installing a module is placing its folder; removing it is deleting the folder.
No server rebuild is needed to turn a feature on or off, only a restart.

> Modules are trusted, executable code. They run with your server's permissions. Only the modules published in
> this repository have been reviewed. Install modules from other sources at your own risk.

## How to install a module

1. Open the module's folder below (or download its latest release `.zip` from the
   [Releases](../../releases) page).
2. Copy the module folder into your server's `game/modules/` directory, so you end up with
   `game/modules/<module-id>/`.
3. Start the launcher. The module appears in the **Installed Modules** panel.
4. Make sure the module is enabled, then restart the server. The module takes effect on the next start.

To uninstall, disable the module, then delete its folder from `game/modules/`. Any data a module stored in the
database is kept until you choose the explicit, opt-in cleanup action in the launcher.

## How to submit a module

Submissions are handled through the server's Discord. Use the **Submit a Module** button in the submissions
channel. A private channel opens where you upload your files and describe what the module does. After it passes
review it is published here.

Before you submit, read [CONTRIBUTING.md](CONTRIBUTING.md) and the module format in
[docs/MODULE_FORMAT.md](docs/MODULE_FORMAT.md). The [`template-module/`](template-module) folder is a ready
skeleton you can copy to start a new module.
